# ch03 检索链路

三个脚本串成一条链路：切分 → 建索引 → 召回初测。只依赖 Python 标准库，离线可复现。

```bash
cd books/rag-project
python src/ch03/chunk.py
python src/ch03/index.py
python src/ch03/eval.py
```

`index.py` 会在同目录写一份 `index.json`（向量与块的落盘结果），可删，重跑会重建。

## 文件职责

| 文件 | 职责 | 关键点 |
| --- | --- | --- |
| `chunk.py` | 按业务结构切分 | 切点取自「现象 / 处理 / 结论」，超长段按句号断 |
| `index.py` | 向量化与索引 | 字符二元组哈希，先落盘再暴力检索 |
| `eval.py` | 召回初测 | 20 条金标，输出排名与未命中清单 |
