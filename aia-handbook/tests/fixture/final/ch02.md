## 正文

### 2.1 连接方式的选择

【重要】直连生产库有风险。更稳的做法是走只读从库。只读从库的延迟通常可以接受，风险却小得多。选哪条路取决于你能拿到什么权限。

| 方式 | 风险 | 适用 |
| --- | --- | --- |
| 直连主库 | 高 | 不推荐 |
| 只读从库 | 低 | 推荐 |

### 2.3 处理字段差异

线上字段名和 csv 不一致。这一步很简单，写个映射表就行。但映射表要进版本管理，否则下次换人接手就没人知道对应关系。

| csv 字段 | 数据库字段 |
| --- | --- |
| 工单号 | ticket_no |
| 描述 | description |

### 2.4 验证结果一致

抽十条工单，和 csv 对比。不一致就先查字段映射。具体排查顺序见第 3 章第 2 节。

| 检查项 | 通过标准 |
| --- | --- |
| 条数 | 与 csv 一致 |
| 内容 | 抽样一致 |
