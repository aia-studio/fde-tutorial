# 附录 E 常见问题

## Ch01

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 乱码 | 编码不对 | 先 utf-8-sig，再 gbk |
| 空结果 | 关键词太窄 | 截取问题前几个字 |
| 有结果但没原文 | 只取了 id | 返回 description |
| 演示时快，换数据就慢 | 数据量变大 | 先记录耗时，Ch03 再优化 |
| 演示全成功 | 客户以为不会错 | 留一条查不到的样本 |

## Ch02

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 检索到的块只有半句话 | 按字数硬切 | 改成按句切，接缝处补整句重叠 |
| 一条工单占满前五名 | 同工单多块都进候选 | 按工单号去重，只留名次最高的一块 |
| 改了工单但答案没变 | 只追加没删除 | 先删后插，放同一个事务 |
| 换模型后程序报维度错 | 维度写死在表或代码里 | 维度从向量长度读，重算全量 |
| 短工单检索不到 | 尾部碎块没并回 | 尾块低于阈值时并入上一块 |

## Ch03

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 第一名分数很低 | 说法与语料差得远 | 先看是不是召回失败，别急着调阈值 |
| 加了过滤后一条都不剩 | 条件写错或标注不全 | 去掉条件对照跑一次 |
| 前五名全是同一工单 | 同工单多块入候选 | 按工单号去重 |
| 调完参数评估变好，上线变差 | 样本太少，过拟合 | 扩样本，或换一批没调过的题 |
| 分数拿来当置信度对外承诺 | 跨查询不可比 | 用覆盖率等可解释的量替代 |

## Ch04

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 引文在原文里找不到 | 模型改写过，或拼接加了前缀 | 只保留子串，前缀放到展示层 |
| 引文很长但没重点 | 整段贴上去 | 截到一到两句，超长就断在句号 |
| 该拒答时硬答 | 只看相似度，没看覆盖率 | 加范围判定，两者都过才作答 |
| 该答时拒了 | 阈值按别的打分口径标的 | 换检索器后重标阈值 |
| 拒答后客户更生气 | 只说不知道，没给下一步 | 话术里必须带一个动作 |

## Ch05

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 两路分数直接相加 | 量纲不同，一路永远赢 | 改用名次融合 |
| 前五名里同一工单占三条 | 没按工单去重 | 融合后去重再截断 |
| 加了 BM25 后短查询变差 | 短查询词少，稀有词权重被放大 | 对极短查询回退到向量一路 |
| 重排后延迟翻倍 | 候选池太大 | 收小候选池，或只对前若干条重排 |
| 拒答阈值突然失灵 | 分数口径从余弦变成名次 | 统一用置信度字段，重标阈值 |

## Ch06

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 总分涨了但体验差 | 指标合成掩盖退化 | 分开看四项 |
| 引用率虚高 | 分母算了拒答题 | 分母只算回答题 |
| 成本超预算 | 上下文塞太多 | 取前三块 |
| 上线后卡顿 | 只看平均延迟 | 看 P95 并加超时 |
| 调参后无法比较 | 评测集被改过 | 冻结评测集 |

## Ch07

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 第三轮答成第一轮的问题 | 改写只补了产品，没换话题 | 只补槽位，不重复旧故障词 |
| 越聊越慢越贵 | 历史全文都拼进提示词 | 状态只留实体，轮次设上限 |
| 刷新页面就失忆 | 状态放在进程内存 | 落到会话存储，键用会话号 |
| 超范围问题被硬答 | 先改写后判范围 | 顺序倒过来，先判再改 |
| 两家客户会话串了 | 状态键用了用户号 | 键改成会话号 |

## Ch08

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 同一问题在清单里出现两次 | 没做归一化去重 | 按归一化问句去重 |
| 一直在补语料但没效果 | 误拒被当成漏召 | 分类时看期望工单在不在前五 |
| 重建后效果变差 | 切到了半成品索引 | 副本上建，校验过再换名 |
| 灰度期间客户投诉答案不一致 | 按请求分桶 | 改成按会话号分桶 |
| 月报数字对不上月 | 分母换了口径 | 固定分母并写进口径说明 |
