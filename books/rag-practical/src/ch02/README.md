# ch02 切分与索引

无第三方依赖，Python 3.13 实测（书中标注 3.12，代码只用标准库）。

先造数据，再切分、嵌入、建索引：

```bash
cd src
python -m data.gen_tickets
python -m ch02.chunk
python -m ch02.embed
python -m ch02.index build
```

单条工单增量更新（块数不变，说明是替换不是追加）：

```bash

```

索引文件落在 `data/index.db`，删掉重跑 `build` 即可复原。
