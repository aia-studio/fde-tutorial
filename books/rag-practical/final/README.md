# RAG 实战：从零搭一个带引用的问答服务

给能调通大模型 API、但没做过检索的后端工程师，用八章搭出一个带引用、能拒答、可评测、能持续修的客服问答服务。

## 怎么读

- 快速路径：必读小节 + 每章小结
- 完整路径：顺序读
- 复习路径：自查清单 + 常见坑

## 目录

| 章 | 标题 | 一句话 |
| --- | --- | --- |
| 01 | 跑通最小链路 | 半小时内让问题进、答案出 |
| 02 | 切分与向量化 | 把文档变成可检索的块与向量 |
| 03 | 接上向量检索 | 用 Top-K 与过滤拿到候选 |
| 04 | 引用与拒答 | 让每个答案带原文，该拒就拒 |
| 05 | 混合检索与重排 | 补上字面检索，再谈重排收益 |
| 06 | 评测与上线 | 用 20 题基线决定能不能上线 |
| 07 | 多轮对话与上下文 | 让系统记住前两轮说过的产品 |
| 08 | 运营与迭代 | 把差评、语料、灰度做成常规动作 |

## 怎么跑代码

```bash
cd rag-practical
python -m ch01.demo
```

- Mock 模式：开启，没有 API Key 也能跑通
- 版本基准：见 `versions.lock`
