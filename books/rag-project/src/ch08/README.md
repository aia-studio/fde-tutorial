# ch08 项目收尾与知识转移

三个脚本：终验证据、交接演练、需求边界。只依赖 Python 标准库。

```bash
cd books/rag-project/src
python -m ch08.signoff
python -m ch08.handover
python -m ch08.boundary
```

`signoff.py` 与 `handover.py` 都跑两轮：第一轮暴露缺口，补证或补文档后第二轮通过。
两轮数据都写死在脚本里，改完可以直接对照。
