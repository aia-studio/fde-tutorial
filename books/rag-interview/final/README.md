# RAG 面试通关：八个高频考点

给准备 AI 应用岗面试的工程师，用八个高频考点把 RAG 讲到「被追问也答得住」。

## 怎么读

- 快速路径：必读小节 + 每章小结
- 完整路径：顺序读
- 复习路径：自查清单 + 常见坑

## 目录

| 章 | 标题 | 一句话 |
| --- | --- | --- |
| 01 | 什么是 RAG | 30 秒讲清它解决什么、不解决什么 |
| 02 | 切分策略怎么选 | 按业务结构解释切分，不背参数 |
| 03 | 向量检索为什么会漏 | 分清三类失效并给出验证顺序 |
| 04 | 混合检索与重排 | 说清何时值得上、何时是浪费 |
| 05 | 幻觉怎么定位 | 区分检索缺失与生成越界 |
| 06 | 怎么评测 RAG | 设计一套能执行的评测 |
| 07 | 系统设计题：设计一个 RAG | 按约束给出可落地的方案 |
| 08 | 开放题与反问 | 用失败案例证明判断力 |
