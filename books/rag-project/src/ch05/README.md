# ch05 联调与压测

三个脚本：协议联调、并发压测、故障演练。只依赖 Python 标准库。

```bash
cd books/rag-project
python src/ch05/integration.py
python src/ch05/loadtest.py
python src/ch05/drill.py
```

压测是模拟，不是真实服务。用它验证判定逻辑与报告格式；接客户环境时把 `one_round` 换成真实发压。

## 实测输出

### integration.py

```
请求校验
  合法    通过
  缺字段  缺字段 channel
  类型错  question 类型应为 str

响应校验
  必填字段：4 个，校验通过
  幂等：同一问题重复提交，缓存命中 True，检索调用仍为 1 次

时序
  1. 客服系统 → 问答服务     session.open 带坐席工号与租户标识
  2. 问答服务 → 客服系统     session.opened 返回会话号，后续请求复用它
  3. 客服系统 → 问答服务     question 带问题原文与工单号
  4. 问答服务 → 检索         取候选并记录 trace_id
  5. 问答服务 → 模型         只带候选片段，不带全库
  6. 问答服务 → 客服系统     answer + citations + trace_id
```


### drill.py

```
场景        期望      实际      结论  说明
正常        normal    normal    通过  首次成功
检索超时    degraded  degraded  通过  检索降级为关键词兜底
模型 5xx    handoff   handoff   通过  模型调用 2 次均失败
从库断连    abstain   abstain   通过  只读从库连接被重置

演练 4 个场景，失败 0 个
  正常 对客回复：主轴异响多为轴承缺油。
  检索超时 对客回复：只找到少量相关记录，先给出关键词结果供参看。
  模型 5xx 对客回复：答案生成暂不可用，已转人工处理。
  从库断连 对客回复：现在查不到工单记录，请过一会儿再试或转人工。
```

## 文件职责

| 文件 | 职责 | 关键点 |
| --- | --- | --- |
| `integration.py` | 协议联调 | 字段校验、幂等、六步时序 |
| `loadtest.py` | 延迟与并发 | 输出 P50/P95/P99 与错误率，按预算判定 |
| `drill.py` | 故障演练 | 四种故障各给一个降级出口 |
