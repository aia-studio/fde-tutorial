# 写作宪法

## 类型基线
- genre: practical
- 骨架、标注体系、练习形式：见 genres/practical.md，本文不重复
- 语体、事实纪律、通用反模式：见 genres/_core.md

## 本书的差异（只写这些）
- 贯穿项目固定为「客服工单问答助手」，客户名统一为「华阳精工」，不得出现真实企业名。
- 全书只用一个案例：客服工单。不引入第二个行业。
- 代码统一 Python 3.12，向量检索先用 SQLite + numpy，不提前引入向量库。
- 术语「工单」专指客服工单，不指研发工单。
- 每章「常见坑」必须来自真实排查顺序，不写想象的问题。
