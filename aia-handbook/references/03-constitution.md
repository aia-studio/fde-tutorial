# 阶段 2 · 宪法

> 目标：产出一份**批量写作前锁死**的写作规范，以及术语表初版。
> 宪法的价值不在内容多全，而在**冻结**。没冻结的规范等于没有。

## 一、不要重写 genre

`genres/` 里已经有四套类型的完整骨架、标注、练习、反模式。
`03-style-guide.md` 只写**差异**，重复的部分一律引用了事：

```markdown
# 写作宪法

## 类型基线
- genre: practical（+ project）
- 骨架、标注体系、练习形式：见 genres/practical.md，本文不重复
- 语体、事实纪律、通用反模式：见 genres/_core.md

## 本书的差异（只写这些）
- 客户固定为「华阳精工」，所有现场故事围绕它，不得出现真实企业名
- 全书只用一个贯穿项目，章节不得引入第二个案例
- 图表统一出 SVG，正文不嵌 Mermaid 源码
- 术语「工单」在本书中专指客服工单，不指研发工单
```

**篇幅判据：** 超过 200 行说明在重复 genre，删。

## 二、四条不能自创的东西

这四项由脚本消费，必须与 genre 完全一致。想改就改 genre，别在书级改：

| 项 | 为什么 |
| --- | --- |
| 骨架段的别名表 | `check.py` 按别名匹配 H2，自创标题 = 直接判缺段 |
| 标注白名单 | 越界即报错 |
| 禁用词表 | 从 `_core.yaml` 读，书级加词只能追加到 `book.yaml` |
| 统计口径 | 字数、句长、段长全按 `_core.yaml` 算 |

书级唯一能改的是**追加**：`book.yaml` 的 `claims.assertion_words` 加领域词，
`limits.*` 调阈值。不能改语义。

## 三、术语表初版

位置 `.book/glossary.json`，上限 `book.yaml` 的 `max_core_terms`（默认 40）。

**抽取方法：**

1. 从 `02-toc.md` 的章标题里提名词（一章标题里的名词几乎必然是核心概念）
2. 从 `00-positioning.md` 的学习目标里提动词宾语
3. 合并去重，得到 60–80 个候选
4. **砍到上限以内**——砍的过程就是判断"哪些概念读者真的需要记住"

每条必须有定义，不许只有名字：

```json
{"id": "C007", "zh": "薄切片", "en": "Thin Slice",
 "def": "先端到端跑通一条最窄链路，再逐步加厚",
 "first_chapter": "ch03", "aliases": ["窄切片"]}
```

`first_chapter` 现在填目录里的预计首现章，统稿时用实际首现校正。

**判据：** 如果两个概念的 `def` 写出来几乎一样，合并它们。
术语表里出现近义词对，说明概念没收敛。

## 四、文风指纹初值

直接复制 genre 的 `fingerprint` 块，标记来源：

```json
{"source": "genre-default", "calibrated_at": null, "metrics": { ... }}
```

第一波写完后自动重算并覆盖（`source: calibrated`，带宽 ×1.2）。
**现在不要手调这些数字**——没有样本的中位数是拍脑袋。

## 五、冻结

宪法定稿后计算哈希，写进文件尾：

```markdown
<!-- frozen: sha256:8f3a... 2026-10-29 -->
```

之后任何写手 agent 只读不写。要改必须：

1. 显式解冻，在 `progress.md` 记录原因
2. 改完重新冻结
3. **重跑所有已完稿章节的闸门**——宪法变了，旧稿可能不再合规

第 3 条最容易被跳过，也是"改了规范但书没跟上"的根源。

## 六、产出与验收

```
03-style-guide.md          差异版宪法（≤200 行）+ 冻结哈希
.book/glossary.json        术语表（≤ max_core_terms 条）
.book/style-fingerprint.json  指纹初值（source: genre-default）
```

- [ ] 宪法没有重复 genre 的内容
- [ ] 骨架别名表与 genre 完全一致（逐条比对）
- [ ] 每个术语都有 `def`，且没有两条定义雷同
- [ ] 术语数 ≤ `max_core_terms`
- [ ] 已写入冻结哈希
- [ ] 书级追加项（断言词、阈值）写在 `book.yaml` 而不是宪法里

## 七、常见的退化

| 退化 | 后果 |
| --- | --- |
| 宪法写成 500 行的完整规范 | 写手读不完，实际执行的还是 genre 默认 |
| 术语表塞 80 条 | 读者记不住，等于没有术语表 |
| 自创骨架标题（「开场白」代替「场景开场」） | 闸门判缺段，返工 |
| 冻结后又偷偷改 | 前后章节按两套规范写，统稿时才能发现 |
| 指纹数字手工调成"好看"的值 | 校准失去意义，所有章节都会"通过" |
