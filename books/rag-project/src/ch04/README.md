# ch04 引用与拒答

两个脚本：一个把答案对回原文，一个在证据不足时拦住答案。只依赖 Python 标准库。

```bash
cd books/rag-project
python src/ch04/cite.py
python src/ch04/abstain.py
```

## 实测输出

### cite.py

```
工单      段    偏移  字数  回切校验
HY-1002   现象  3     21    一致
HY-1002   处理  28    20    一致
HY-1002   结论  52    12    一致

渲染结果：
主轴异响多半是轴承缺油，补脂后可以消除。 [HY-1002 · 现象][HY-1002 · 处理][HY-1002 · 结论]

链接：
  现象 → https://ticket.huayang.example/t/HY-1002#p1
  处理 → https://ticket.huayang.example/t/HY-1002#p2
  结论 → https://ticket.huayang.example/t/HY-1002#p3
```

`回切校验`这一列是重点：拿引用的起始偏移与长度回切原文，必须与引用逐字相同。整段搬运做不到这一点，因为模型改写过。

### abstain.py

```
阈值：分数 ≥ 0.3，支撑词 ≥ 2，冲突优先
用例          分数    支撑词  冲突  结论
轴承缺油      0.62    4       否    作答
换刀停顿      0.41    3       否    作答
滤网堵塞      0.35    2       否    作答
模糊提问      0.24    3       否    拒答（no_evidence）
只对一个词    0.38    1       否    拒答（low_match）
两条记录矛盾  0.55    3       是    拒答（conflict）

统计：answer 3，conflict 1，low_match 1，no_evidence 1

对客话术（需客户签字）
  no_evidence: 这个工单库里没有查到相关记录，建议转人工确认。
  low_match: 找到的内容与问题关联不大，为避免误导，先不给结论。
  conflict: 查到两条互相矛盾的处理记录，需要客服主管确认后再答。
```

判定顺序是冲突 → 分数 → 支撑词。把冲突放第一位，是因为两条记录互相矛盾时，分数往往不低，先看分数会直接答错。

## 文件职责

| 文件 | 职责 | 关键点 |
| --- | --- | --- |
| `cite.py` | 生成与校验引用 | 抽关键句，带偏移与锚点，可回切 |
| `abstain.py` | 拒答判定 | 三类拒答各有一句对客话术 |
