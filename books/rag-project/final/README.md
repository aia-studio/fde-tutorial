# RAG 交付实录：一个客服问答系统的八个阶段

给要交付 AI 项目的 FDE 与解决方案工程师，按八个阶段走完一个客服问答系统的需求、接入、检索、引用、联调、上线、二期与收尾。

## 怎么读

- 快速路径：必读小节 + 每章小结
- 完整路径：顺序读
- 复习路径：自查清单 + 常见坑

## 目录

| 章 | 标题 | 一句话 |
| --- | --- | --- |
| 01 | 需求澄清与验收标准 | 把模糊需求变成能签字的验收项 |
| 02 | 数据接入与清洗 | 把工单数据安全接进来 |
| 03 | 检索链路搭建 | 让系统能找对候选 |
| 04 | 引用与拒答 | 让答案有依据、该拒就拒 |
| 05 | 联调与压测 | 证明它在真实流量下不塌 |
| 06 | 上线与复盘 | 灰度、监控、复盘、交接 |
| 07 | 二期扩展 | 接第二条业务线，先定范围与权限边界 |
| 08 | 项目收尾与知识转移 | 终验、交接、复盘、划定产品边界 |
