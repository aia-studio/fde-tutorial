# ch06 上线与复盘

两个脚本：灰度判据与上线后监控。只依赖 Python 标准库。

```bash
cd books/rag-project
python src/ch06/canary.py
python src/ch06/monitor.py
```

### monitor.py

```
当日指标
  请求 1000 次，作答 830，拒答 150，错误 20
  可用性      98.00%
  拒答率      15.0%
  空召回率    16.8%
  引用点击率  34.0%
  P95         2180 毫秒

告警
  ✗ 空召回 16.8% 超阈值

为什么盯后三项：可用性满分时，答案仍可能是「查不到」或「答了没人点」。只报警可用性，等于放弃质量。
```

空召回超阈值的处理不是调阈值，是回去补语料：产品手册当初以「人工导出、未整理」排在接入清单末尾，上线后那批问题全部落进空召回。

## 文件职责

| 文件 | 职责 | 关键点 |
| --- | --- | --- |
| `canary.py` | 灰度判据 | 每档四项指标，停与放都有理由 |
| `monitor.py` | 上线后监控 | 可用性之外的三个质量指标 |
