# 写作宪法

## 类型基线
- genre: project
- 骨架、标注体系、练习形式：见 genres/project.md，本文不重复
- 语体、事实纪律、通用反模式：见 genres/_core.md

## 本书的差异（只写这些）
- 客户固定为「华阳精工」，项目固定为「客服工单问答」，不得出现真实企业名。
- 每个阶段必须有交付物、验收人、风险登记、复盘三段。
- 每节的「决策」必须写当时放弃了什么，不能只写选了什么。
- 返工必须记录：现象、原因、改法、代价。
- 工期数字统一用「人天」，不写「大概几天」。
