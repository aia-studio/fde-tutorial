耗时是这台机器上的实测值，换机器会变；比绝对值更有意义的是两档之差（融合 vs 融合+重排）。

三档链路的对照要跑 Ch06 的评测脚本（20 题里 15 题有标准答案）：

```bash
python -m ch06.eval --compare
```

```text
链路        第一名命中     前五名命中
纯向量       12/15        14/15
混合        12/15        15/15
混合+重排     14/15        15/15
```

混合把漏掉的那条拉回前五，重排再把两个名次挪正。收益都只有一两条题，
样本一多是否还成立，得自己重跑。
