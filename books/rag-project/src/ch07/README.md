# ch07 二期扩展

四个脚本：接入评估、权限收窄、索引升级、方案汇总。只依赖 Python 标准库。

```bash
cd books/rag-project/src
python -m ch07.intake
python -m ch07.tenancy
python -m ch07.upgrade
python -m ch07.report
```

`report.py` 汇总前三节的结论，四条闸门都通过才输出「可提交评审」。
脚本里的检索分数是固定的，用来验证过滤位置，不验证召回效果。

### tenancy.py

```
检索位置对比（k=3，身份：华阳精工 / 售后）
  前置过滤  模型看到 3 条：S1 / S2 / S3
            越权 0 条
  后置过滤  模型看到 3 条：L1 / F1 / S1
            越权 2 条，展示层可见 1 条
  卡片能藏，答案藏不住。空出来的名额也补不回来。

越权扫描（4 个问题 × 5 个身份，共 20 次）
  前置过滤  越权 0 条
  后置过滤  越权 40 条

断言通过：前置过滤下，进入模型的每一条都属于当前租户与当前组。
口径：越权指进入模型上下文的文档里，租户不同或受众组不在当前身份中。
```
